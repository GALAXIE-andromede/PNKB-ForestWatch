⚠️ Le problème

Le PNKB est l'une des dernières forêts primaires d'Afrique centrale, refuge du gorille de Grauer et de milliers d'espèces uniques. Mais la déforestation avance souvent en silence : les clairières illégales sont découvertes trop tard, quand les dégâts sont déjà immenses.

🛰️ Notre solution : un œil dans le ciel, 100 % gratuit

🛰️

Scan hebdomadaire

Chaque lundi, les images Sentinel-2 (Copernicus/ESA) sont analysées automatiquement pour détecter les pertes forestières.

🚨

Alertes instantanées

Une perte forestière détectée ? Une alerte part sur Telegram pour tous les abonnés — riverains, ONG, gardes du parc, citoyens du monde.

🗺️

Carte interactive

Un dashboard public montre où les pertes ont été détectées, avec leur localisation et leur superficie estimée.

💯

Toujours gratuit

Imagerie publique, hébergement GitHub Pages, alertes Telegram : aucun frais, aucune donnée vendue, pour toujours.
